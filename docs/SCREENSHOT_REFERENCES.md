# Screenshot reference set

This project is intentionally grounded in the real visuals and machine behavior of the SGI Indy and IRIX environment.

## Reference images

- PROM / startup screen target: [0001.png](../0001.png)
- IRIX 5.3 desktop / system view: [irix53.png](../irix53.png)
- user Indy / system manager setup screenshot: [Captura_de_tela_20260830_012258.png](../Captura_de_tela_20260830_012258.png)

## Intended use

These screenshots will be used as the visual targets for:

- the Indy PROM boot menu and early console look
- the IRIX 5.3 desktop shell and system manager layout
- the final target appearance of the emulator window when it reaches a usable SGI workstation state

## Project goal

The emulator should eventually reach a state where its interface and boot flow resemble the classic SGI Indy / IRIX visual style, while still maintaining a functional emulator backend for the CPU, memory, PROM, graphics, storage, and network components.
