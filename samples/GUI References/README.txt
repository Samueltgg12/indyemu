These Buttons and sliders, windows, widgets, motif widgets and qt theme references/images in the root folder are from the MaXX Interactive Desktop Project, An Reimplementation of The IndigoMagic Desktop for linux.

Use these to build the gui in the IndigoMagic Look.

These references are from the "enhanced look and feel" from MaXX Interactive Desktop which are improved/enhanced versions of the IndigoMagic Look.

IRIX 6.5 Screenshots are references screenshots of the IRIX Interactive Desktop for our gui.

IRIX 5.3 Screenshots are references screenshots of The Older IndigoMagic Desktop of IRIX 5.3 for our IndigoMagic Look/Theme

sgi-enhanced has colors, the SGI red cursor, docs and icons to use for our gui and integrate it for the cursor, colors, and icons of our Qt GUI.

SystemManager.png is what we will use as the init screen of IndyEMU GUI, the hardware summary screen is what the main screen of the launcher will be based on. the launcher will basically be the hardware summary screen of SystemManager.png with buttons and tabs to configure the machine and a launch button to launch the machine with the configuration made by the user, the launch button will execute the framebuffer window in a display tab or a seprate window if the user wants one, alongside debugging tools and other essential tools, the machine/model name on top of the machine image on the launcher screen can be changed at anytime alongside the machine name on bottom. the IRIX Version is what we will change it to the launch button, The Shared Resources window is where all disk/cd/drives options are in and can be changed alongside the window tabs for disks. The Tools tab will be where all debugging/logging tools will be located. the hardware tab is where we can also change the configuration of the machine. the file tab is where we can exit, export the config to a toml file and other file operations. The Help tab will bring help manuals and help/support of the emulator. the activity tab will be for logging purposes. selected is the tab that bring options to selected icons on shared Resources. The software tab will be a tab for the prom's, and other software. this is what we want the GUI To Look As. the title window will be from the sgi-enhanced folder where it will be adapted for Qt. right clicking on any empty part of the window will bring a exit button to exit the GUI. SystemManager.png is what the launcher phase of IndyEMU GUI will be, it's before the launch button is clicked to start the emulation with the said configuration made by the user.
